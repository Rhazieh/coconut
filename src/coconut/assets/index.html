    Coconut v1.3.1

    Minimalist, local-first, eye-comfort Markdown viewer for Linux (Wayland & X11).

    Credits & Open Source Licenses
    • Created by Maximiliano Cano (Rhazieh) — MIT License.
    • Typography: Atkinson Hyperlegible Next (Braille Institute) — SIL OFL 1.1.
    • Rendering: libcmark-gfm / python-markdown + PyQt6 QtWebEngine.
    How to contribute

    Coconut stays viewer-only, offline, and distraction-free. You can report bugs, suggest ergonomic improvements, or open pull requests on GitHub.

    Extensions

    For future languages support

    Optional lightweight modules for .txt, .epub, .js, .ts, .java, .html and more will be installable on demand with an Add button—text-focused, zero compiler bloat.
