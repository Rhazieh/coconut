    Coconut v1.3.1

    Minimalist, local-first, eye-comfort Markdown & code reader for Linux (Wayland & X11).

    How to contribute

    Coconut stays local-first, offline, and distraction-free. You can report bugs, suggest ergonomic improvements, or open pull requests on GitHub.
