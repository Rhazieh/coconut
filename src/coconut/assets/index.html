    Coconut v1.2.0

    Minimalist, local-first, eye-comfort Markdown viewer for Linux (Wayland & X11).

    How to contribute

    Coconut stays viewer-only, offline, and distraction-free. You can report bugs, suggest ergonomic improvements, or open pull requests on GitHub.
